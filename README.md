# SpeechSteps — Остров Эха

Веб-демо для хакатона: ребёнок ведёт лисёнка указательным пальцем перед камерой и оживляет три места в 3D-саду. У цветка, рыбки и фонарика камера замечает движения рта, а короткие подсказки предлагают поиграть со звуками «И», «У», «А». Дополнительная история превращает звук в свет, пробуждает цветок и запускает мельницу. Экран для взрослого показывает фактические игровые действия.

По умолчанию приложение открывает этот компактный сценарий. Полная платформа с кабинетами сохранена в исходниках и включается отдельно. Подтверждённое требование пользователя — **«веб-камера становится контроллером»**. Официальный регламент и критерии жюри не предоставлены; соответствие неизвестному регламенту не заявляется.

## Запуск

```bash
npm install
npm start
```

Откройте [Остров Эха](http://localhost:8081/play-world). Для камеры нужен `localhost` или HTTPS и разрешение браузера. Первый запуск распознавания требует сети для загрузки MediaPipe, WASM и моделей руки и лица.

| Адрес | Назначение |
| --- | --- |
| `/play-world` | Заставка с основным входом «Играть с камерой» и дополнительной историей |
| `/play-world?mode=camera` | 3D-сад с тремя короткими упражнениями и камерой-контроллером |
| `/demo/results` | Результаты текущего профиля ребёнка |

В деморежиме `/parent/progress` ведёт на результаты, остальные старые адреса — на остров. Камера и микрофон не включаются от открытия ссылки.

## Короткое прохождение

1. Нажмите «Играть с камерой», затем «Играть жестами» внутри 3D-сцены. Разрешите камеру.
2. Покажите руку с вытянутым указательным пальцем. В предпросмотре видны кончик пальца и нейтральная зона. Двигайте палец, чтобы вести лисёнка к подсвеченной остановке; верните его в центр для остановки.
3. У цветка улыбнитесь с подсказкой «И», у рыбки округлите губы с «У», у фонарика откройте рот с «А». В каждой игре два коротких повтора с расслаблением между ними. Камера управляет оживлением объекта; звук не записывается и не оценивается.
4. После трёх остановок откройте результаты. Там указаны время, источник каждого игрового повтора и отдельно реально использованное управление ходьбой: камера, клавиатура / джойстик или оба способа.

Если камера недоступна, можно выбрать клавиатуру или экранный джойстик: WASD / стрелки — движение, Q/E — поворот вида, пробел — прыжок. На остановках есть явная кнопка помощи. Она завершает игровой повтор вручную и так отмечается в результате. Движение с WASD и упражнение, распознанное камерой, могут использоваться вместе.

При потере фокуса прогулка ставится на паузу: движение прекращается, устройства отключаются, время паузы не входит в результат. Продолжение и повторная игра требуют явного выбора управления. Если 3D-сцена не загрузилась или потеряла WebGL-контекст, появляется экран с повторным запуском и возвратом на остров.

Дополнительная история с Үнчиком состоит из трёх сцен: любой звук зажигает Искру на берегу, касание пробуждает цветок, три коротких сигнала с паузами вращают мельницу. Её можно полностью пройти касаниями. Подсказки озвучиваются русским голосом браузера; анализ микрофона приостанавливается на время речи и короткую паузу после неё.

## Данные и ограничения демо

- Видеокадры обрабатывают HandLandmarker и FaceLandmarker в браузере. Приложение не записывает и не отправляет видео или аудио ребёнка. Точки лица, руки и коэффициенты мимики не сохраняются.
- Камера включается по кнопке; её можно выключить. При завершении маршрута или выходе из сцены медиапотоки останавливаются. В 3D-демо микрофон не нужен.
- Последний завершённый маршрут сохраняется по ребёнку в `speechsteps:camera-route:v1:<childId>`. Хранятся три завершённые остановки, их идентификаторы, источник действий и число игровых повторов, длительность, время завершения, способ управления ходьбой и расстояния от камеры и ручного ввода. Расстояния выражены в игровых единицах. Старые результаты маршрута из трёх Искр остаются читаемыми и помечаются как прежний маршрут.
- История сохраняет этапы, завершённые действия, время и использованные способы ввода в `speechsteps:echo-journey:v1:<childId>`. Её можно продолжить после перезагрузки без автоматического включения микрофона.
- Незавершённый 3D-маршрут начинается заново при повторном входе; история поддерживает продолжение. Старые сохранения полного мира не перезаписываются этим маршрутом.
- Это игровые результаты: камера замечает движения рта, но не проверяет, какой звук произнесён. Оценка произношения, правильности выдоха и медицинские выводы не формируются. Демо не создаёт клинические попытки и не синхронизирует игровой прогресс с сервером.
- Недоступное или повреждённое локальное сохранение показывается отдельно. Между браузерами демоданные не переносятся.
- Если браузер блокирует запись, последний результат и этап истории остаются доступны при переходах внутри приложения до перезагрузки. Интерфейс прямо сообщает об этом ограничении. Ссылка продолжения открывает сохранённую сцену; для законченной истории — её итог.

Границы демонстрации, защищённое поведение и использованные источники описаны в [docs/hackathon-scope.md](docs/hackathon-scope.md).

## Стек и файлы

Vite, React DOM, TypeScript, React Router, Zustand, Three.js r149, MediaPipe Tasks Vision, Web Audio и Lucide React. React Native не используется. Модели и распознавание подключаются при явном запуске камеры; 3D-сцена загружается отдельно от иллюстрированной истории.

| Путь | Содержимое |
| --- | --- |
| `web/App.tsx`, `web/demo/config.ts` | Выбор деморежима и его маршруты |
| `web/demo/` | Проверка и отображение сохранённых игровых результатов |
| `web/echo/` | Иллюстрированная история, микрофон, касания и сохранение |
| `app/play-world.web.tsx`, `app/free-roam-world.web.tsx` | Вход в игру и мост к 3D-сцене |
| `data/world/` | 3D-мир, персонажи, управление рукой и упражнения с движениями рта |
| `public/echo-journey/`, `public/world-intro/` | Созданные фоны и цветок, предоставленные пользователем изображения Үнчика |
| `docs/echo-journey-art.md` | Происхождение иллюстраций и промпты |
| `store/`, `data/`, `i18n/`, `components/` | Общие данные, локализация и компоненты полной платформы |

Команды для разработчика:

```bash
npm run build
npm run typecheck
npm run test
```

Команды здесь описывают доступные проверки, а не утверждают, что конкретное устройство или камера уже проверены. Реальное отслеживание руки и движений рта нужно проверять с камерой; подстановка landmarks и blendshapes проверяет только логику управления.

Возможности визуального распознавания описаны в [руководстве MediaPipe Face Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker/web_js). Выбор игровых подсказок не заменяет индивидуальную логопедическую программу: [ASHA описывает подбор терапии с учётом конкретных речевых трудностей](https://www.asha.org/practice-portal/clinical-topics/articulation-and-phonology/). В демо эти задания используются для игры с движениями и звуками, без заявления о лечебном эффекте.

## Полная платформа

Значение `VITE_APP_MODE=full` возвращает прежнюю маршрутизацию из `web/FullApp.tsx`. По умолчанию `IS_HACKATHON_DEMO` определяется условием `import.meta.env.VITE_APP_MODE !== 'full'`.

Для PowerShell:

```powershell
$env:VITE_APP_MODE = 'full'
npm start
```

Чтобы вернуться к демо, остановите сервер, удалите переменную и запустите его снова:

```powershell
Remove-Item Env:VITE_APP_MODE -ErrorAction SilentlyContinue
npm start
```

Для production-сборки режим задаётся перед `npm run build`: Vite подставляет его при сборке.

В полной платформе сохранены:

- **Логопед:** дети, карточки и заметки, конструктор и назначение уроков, каталог и ручной конструктор упражнений, настройки игр, экспорт через печать браузера.
- **Родитель:** общий с логопедом прогресс и задания, подтверждение присутствия для упражнений `requiresParent`, домашняя практика, отчёты, чат, профиль, достижения и лига.
- **Клиника:** команда, клиенты и этапы CRM, расписание, профиль и настройки.
- **Игры:** полный 3D-мир, «Шахта звуков» и сохранённый Phaser-прототип в `echo-island/`. Прототип не является текущим экраном `/play-world`.

Это локальный прототип: демоданные хранятся в браузере, вход в кабинеты не заменяет серверную авторизацию. Модуль `ai/index.ts` использует заглушки; его рекомендации и оценки не являются реальным анализом речи. Необязательная синхронизация полного 3D-мира описана в [server/README.md](server/README.md), Phaser-прототип — в [echo-island/README.md](echo-island/README.md). В деморежиме эти серверные возможности не нужны.
