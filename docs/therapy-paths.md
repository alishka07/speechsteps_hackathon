# Коррекционный путь по логопедическому заключению + сценарии игры

Документ описывает, как строить «путь игры» (долгосрочную траекторию занятий)
на основе логопедического заключения, опираясь на классические методики, и
предлагает идеи интерактивных сценариев для «Острова Эха».

## 1. Логопедические заключения и что предлагают методички

В приложении уже есть заключения (`DiagnosisKey`): дислалия, дизартрия, ФФН(Р),
ОНР, ЗРР (задержка речевого развития), заикание. Для каждого — своя логика
коррекции (по учебно-методической литературе):

| Заключение | Суть | Методики/авторы | Акцент коррекции |
|---|---|---|---|
| **Дислалия** | нарушение звукопроизношения при норме слуха и иннервации | Фомичёва, Коноваленко, Богомолова | постановка → автоматизация → дифференциация нарушенных звуков; подготовительный этап короткий |
| **Дизартрия** | нарушение иннервации речевого аппарата | Архипова, Лопатина | длинный подготовительный этап: тонус, артикуляционная и дыхательная база, моторика, логопед. массаж; медленная автоматизация |
| **ФФН(Р)** | фонетико-фонематическое недоразвитие | Филичева, Чиркина | фонематическое восприятие, звуковой анализ/синтез, дифференциация |
| **ОНР** | общее недоразвитие речи (уровни I–IV) | Левина; Жукова; Филичева/Чиркина; Нищева | комплекс: словарь, грамматика, фразовая и связная речь + звукопроизношение |
| **ЗРР** | задержка речевого развития | Громова, Янушко | стимуляция речевой активности, звукоподражания, словарь, простая фраза |
| **Заикание** | нарушение темпо-ритмической стороны речи | Выгодская/Пеллингер; Селиверстов | дыхание, плавность, темп-ритм, релаксация (не постановка звуков) |

### Универсальная этапность коррекции звукопроизношения

Классическая схема (Фомичёва, Коноваленко) — основа пути для дислалии,
дизартрии, ФФН, частично ОНР:

1. **Подготовительный этап** — артикуляционная гимнастика, речевое дыхание,
   фонематическое восприятие, мелкая моторика.
2. **Постановка звука** — вызывание изолированного звука (по подражанию,
   механически, смешанно).
3. **Автоматизация** — изолированно → слоги → слова → словосочетания →
   предложения → чистоговорки → связная речь.
4. **Дифференциация** — различение смешиваемых звуков (С–З, С–Ш, Ш–Ж, Р–Л,
   Ч–Ть…): изолированно → слоги → слова → речь.
5. **Введение в самостоятельную речь.**

**Порядок звуков (онтогенез):** свистящие (С, Сь, З, Зь, Ц) → шипящие
(Ш, Ж, Ч, Щ) → сонорные (Л, Ль, Р, Рь). Р/Рь — обычно последними.

## 2. Модель пути в коде

`data/therapyPaths.ts` кодирует это как данные:

- `STAGES` — 8 этапов (дыхательная/артикуляционная/моторная/фонематическая
  база, постановка, автоматизация, дифференциация, связная речь) с
  клинической целью и целевыми категориями упражнений + регионами «Острова».
- `PROGRAMS` — для каждого заключения: упорядоченный набор этапов, методика,
  акцент.
- `buildTherapyPath(diagnoses)` — объединяет программы нескольких заключений в
  один маршрут в канонической этапности; помечает, какие заключения требуют
  каждого этапа.

Путь связывает заключение → этапы → категории/регионы. Это даёт логопеду
готовый «коррекционный маршрут», по которому он создаёт уроки (а уроки уже
становятся маршрутом дня в игре). В перспективе путь управляет и прогрессией
карты «Острова» (регионы открываются по этапам).

### Соответствие этап → регион «Острова Эха»

| Этап | Категория | Регион |
|---|---|---|
| Дыхательная база | breathing | Ветряные холмы |
| Артикуляционная база | articulation | Зеркальное озеро |

## 3. Идеи интерактивных сценариев (с сохранением «единой механики»)

GDD требует **одну механику на весь мир** (голос/поза ребёнка оживляет
объект), поэтому интерактивность наращиваем не новыми ядрами, а сценарной
обёрткой и обратной связью:

1. **Сюжетные сцены этапа** — переход между этапами пути оформляется коротким
   событием: Хранитель региона даёт «квест этапа» (несколько упражнений
   подряд с общей историей), по завершении — праздник пробуждения.
2. **Прогрессивная сложность автоматизации** — одно и то же упражнение
   («слова со звуком Р») разворачивается по ступеням: слог → слово → фраза;
   ступень растёт по мере успехов (видна как «уровни объекта»).
3. **Парные сцены дифференциации** — два жителя-«двойника» (С и Ш) просят
   разложить им слова: это уже есть как мини-игра «Сортировка звуков», её
   можно привязывать к этапу дифференциации пути.
4. **Диалоговые сцены** (этап связной речи) — Городок Болтушка, но включается
   ТОЛЬКО после чеклиста приёмки ИИ-диалогов (см. «Рамки ИИ-диалогов»).
5. **Совместные сцены «для двоих»** — упражнения с `adultRequired`/зеркальные
   рожицы: камера сравнивает мимику ребёнка и взрослого (мини-игра «Зеркало»),
   усиливает вовлечённость родителя.

Эти сценарии не вводят новых ядер, но делают путь живым: ребёнок видит, что
двигается по истории, а не выполняет случайные задания.
